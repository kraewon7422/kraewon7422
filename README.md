### 🔬 things I've built

**[piezo_hafs_108](https://github.com/kraewon7422/piezo_hafs_108)**
Measured what a piezo disc *actually* outputs — Arduino waveform capture, real
bench data — then worked backwards from d·g coefficients to design the material
composition. Not a simulation. An actual research log.

**[swarm-sim](https://github.com/kraewon7422/swarm-sim)** · [▶ live demo](https://kraewon7422.github.io/swarm-sim/)
Swarm robots mapping a space together, in your browser. Swarm-SLAM concepts
+ Boids flocking + connectivity constraints, no install needed.

**[double-descent-grokking-lab](https://github.com/kraewon7422/double-descent-grokking-lab)** · [▶ live demo](https://kraewon7422.github.io/double-descent-grokking-lab/)
The textbook bias–variance U-curve breaks sometimes. This one lets you watch
it break — double descent and grokking, simulated numerically in one HTML file.

**[samsung-notes-mcp](https://github.com/kraewon7422/samsung-notes-mcp)**
An MCP server so Claude can read my handwritten Samsung Notes. Read-only,
runs entirely on my own PC. Built it because I was tired of retyping things.
